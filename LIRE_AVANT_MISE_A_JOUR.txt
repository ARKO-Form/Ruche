BEETEND V1.2.1 — ANALYSE VISIBLE DANS LA FICHE COLONIE

Changements :
- Nouvel onglet 🔎 Analyse dans chaque fiche de ruche.
- Bouton visible « Voir l’analyse de ma colonie » depuis Vue générale.
- Après la saisie d’une visite, BeeTend affiche immédiatement l’analyse.
- Une visite suffit pour un premier bilan ; deux visites ou plus pour la comparaison.
- Aucune modification des fiches, des visites, des tâches ni de la structure de stockage.

SAUVEGARDE ET INSTALLATION
1. Depuis l'application iPhone que tu utilises réellement : Données -> Exporter en JSON.
2. Conserve une copie dans Fichiers ET une seconde dans iCloud ou un ordinateur.
3. Vérifie le fichier dans l'application avant la mise à jour. Ne clique pas sur Importer.
4. Sur GitHub dans le dépôt Ruche, remplace les fichiers existants par ceux du dossier décompressé, et Commit changes.
5. Ouvre arko-form.github.io/Ruche/index.html?v=121 dans Safari.
6. Ouvre une ruche : tu dois voir le nouvel onglet « 🔎 Analyse ».
7. Vérifie ensuite que les anciennes données (ruches, visites, tâches) sont conservées.

IMPORTANT : GitHub héberge les fichiers de l'application, pas les données enregistrées.
Ne supprime pas l'application iPhone et n'efface pas les données de Safari.
Cette version n'ajoute pas de sauvegarde cloud ni d'intelligence artificielle connectée.
