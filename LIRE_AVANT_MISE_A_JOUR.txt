BeeTend V1.1.4 — Gestion des tâches par rucher + rappels

IMPORTANT : EXPORTER UNE SAUVEGARDE JSON AVANT LA MISE À JOUR.

1. Dans BeeTend V1.1.3 : Données → Exporter en JSON.
2. Sur iPhone, télécharger puis décompresser BeeTend_V1_1_4_GitHub.zip.
3. Dans le dépôt GitHub ARKO-Form / Ruche, remplacer les fichiers à la racine : index.html, manifest.webmanifest, sw.js, icônes et images.
4. Valider Commit changes, et ouvrir Safari : arko-form.github.io/Ruche/index.html?v=114
5. Ne pas supprimer l’ancienne icône ni effacer les données Safari avant de vérifier les ruches et les visites.

Nouveautés :
- Tâche pour tout un rucher ou une seule ruche, choix du rucher en premier.
- Filtre des tâches par rucher, modification et suppression réversible.
- Alertes visibles dans l’application à échéance.
- Notification système uniquement lorsque BeeTend est ouverte et si le navigateur le permet, après autorisation explicite.
- Export .ics compatible calendrier (nécessite un import dans une application calendrier, pas de synchronisation automatique).

ATTENTION : GitHub Pages seul ne permet pas d’envoyer des notifications push quand l’application est fermée. Il faudra ajouter un backend d’envoi de notifications pour cela.

La clé de stockage reste ruchepilot_v1_data_2026. Aucune réinitialisation automatique.
